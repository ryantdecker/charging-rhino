## Log

Newest first. Format:

```
- YYYY-MM-DD | "Task title" (Project)
  I said: Quick 15 / Agent 8 / Neither. You said: <correction>. Why: <one line>.
```

Time outcomes use the same list:

```
- YYYY-MM-DD | time | <kind of task>: estimate vs actual, what it suggests.
```

Agent outcomes record what happened when a task was handed to an agent. This is the evidence behind `assist`:

```
- YYYY-MM-DD | agent | "Task title" (Project) assist 8 -> clean | rework | failed. <what went wrong or right>.
```
